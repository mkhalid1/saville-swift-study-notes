# Glossary

Terms from Saville's material, your invitation and these notes.

| Term | Meaning |
|---|---|
| **Base value** | The starting figure in a percentage change. Divide the change by this. |
| **Cannot say** | The answer when a passage does not give enough information to decide whether a statement is true or false. |
| **Combination test** | A single test that measures several aptitudes in one sitting. All Swift tests are combination tests. |
| **Diagrammatic Analysis** | The Swift Analysis sub-test on diagrams, sequences and transformations. |
| **Error Checking** | The Swift Comprehension sub-test on proofreading text, checking figures and verifying codes. |
| **IRT, item response theory** | A statistical scoring method that accounts for the difficulty of the specific questions a person answered. Saville uses it for Swift. |
| **LOFT, linear-on-the-fly testing** | A design where each candidate gets a fixed-length test built from a bank of items of equivalent difficulty. |
| **Norm group** | The comparison group a score is set against, such as graduates or professionals and managers. |
| **Operator** | In diagrammatic items, a lettered box that changes a row of shapes in a fixed way. |
| **Sub-score** | The score for one sub-test. Saville advises against using it alone for decisions. |
| **Sub-test** | One part of a Swift test, such as Verbal Analysis. |
| **Swift Analysis Aptitude** | Verbal, numerical and diagrammatic analysis: 24 questions in 18 minutes. For graduate, professional and management roles. |
| **Swift Comprehension Aptitude** | Verbal and numerical comprehension and error checking: 24 questions in 9.5 minutes. For administrative, customer service, operational and commercial roles. |
| **Testlet** | A group of four questions with its own time limit. |
| **Total score** | The overall score across all sub-tests. Saville designed it as the decision-making score. |
| **Transposition** | Two characters swapped in order, such as 906 copied as 960. The most common error-checking trap. |
