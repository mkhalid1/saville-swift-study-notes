# Which Swift test do you have?

"Saville aptitude test" or "Swift test" can mean several different combinations. The two most common are very different in pace and content, so it is worth knowing which one you face before you practise.

## The two main tests side by side

| | Swift Analysis Aptitude | Swift Comprehension Aptitude |
|---|---|---|
| Who it is for | Graduates, trainees, managers, professionals, directors | Administrative, customer service, operational, commercial roles |
| Verbal | Verbal Analysis: understand, interpret and **evaluate** written information | Verbal Comprehension: understand and **interpret** written information |
| Numerical | Numerical Analysis: understand, interpret and **evaluate** numerical data | Numerical Comprehension: understand and **interpret** numerical data |
| Third sub-test | Diagrammatic Analysis: diagrams, sequences and transformations | Error Checking: proofread text, check figures and verify codes |
| Time | 18 minutes | 9.5 minutes |
| Questions | 24 | 24 |

The descriptions in bold are Saville's own wording from its technical summaries. The step from "interpret" to "evaluate" is the main difference in level.

## How to tell which one you have

1. **Read the invitation and the instructions screen.** Saville's candidate page says your platform shows "how long each part takes" and practice questions matched to your assessments. That is the most reliable source.
2. **Look at the role.** A graduate scheme or management role usually points to Analysis. A customer service, admin or operational role usually points to Comprehension. That is a guide based on Saville's stated target roles, not a rule.
3. **Ask the employer** if it is not clear. It is a normal question.
4. **Try Saville's own practice tests for both.** Saville's [practice page](https://www.savilleassessment.com/practice-tests) has a practice test for each, which you can repeat as often as you like.

## If you are still not sure

Prepare for both. The verbal and numerical methods overlap, so the extra work is mainly the third sub-test: Diagrammatic Analysis for one, Error Checking for the other. Start with the [diagnostic](diagnostic.md), which has a short track for each.
