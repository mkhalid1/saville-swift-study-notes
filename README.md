# Saville Swift Study Notes

A free, complete study guide for Saville Assessment's Swift aptitude tests: **Swift Analysis Aptitude** (verbal, numerical and diagrammatic, 18 minutes) and **Swift Comprehension Aptitude** (verbal, numerical and error checking, 9.5 minutes). It covers how each test works, a clear method for all six sub-tests, 24 original practice items with full explanations, how scoring works, and study plans for a week or a weekend. Facts about the tests come only from Saville's own pages and documents, each one [cited](docs/sources.md).

Want to see where you stand first? Take the [free timed Saville Swift practice test on PrepClubs](https://prepclubs.com/free-practice-tests/saville-swift?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=saville-swift), which follows the Swift Analysis format, or the shorter [3-minute diagnostic](docs/diagnostic.md) in this repo.

## Start here

1. **Check which test you have.** Swift Analysis and Swift Comprehension are different tests. Read [which Swift test you have](docs/which-swift-test.md) if your invitation does not say.
2. **Find your weak sub-test.** Take your track of the [3-minute diagnostic](docs/diagnostic.md). It has one item per sub-test.
3. **Fix the weakest one first,** using its guide below, then follow the [7-day plan](docs/study-plans.md#7-day-plan), or the [2-day plan](docs/study-plans.md#2-day-plan) if your link has already arrived.

## Quick facts

| | Swift Analysis Aptitude | Swift Comprehension Aptitude |
|---|---|---|
| For | Graduates, trainees, managers, professionals, directors | Administrative, customer service, operational, commercial roles |
| Sub-tests | Verbal, Numerical, Diagrammatic Analysis | Verbal, Numerical Comprehension, Error Checking |
| Questions | 24 (8 per sub-test) | 24 (8 per sub-test) |
| Time | 18 minutes (6 per sub-test) | 9.5 minutes (4, 4 and 1.5) |
| Clock | Separate limits for each group of four questions | Same |
| Device | Not on a mobile phone, per Saville's practice page | Same |
| Result | One total score plus sub-scores, against a norm group | Same |
| Pass mark | None published | None published |

Sources: Saville's technical summaries for the Analysis and Comprehension ranges (2022), its archived aptitude tests page (June 2026) and its live [practice tests page](https://www.savilleassessment.com/practice-tests), checked 24 November 2026. Saville's live site no longer hosts the technical summaries, so we cite archived copies. See [sources](docs/sources.md) for details.

## The six sub-tests at a glance

| Test | Sub-test | You are asked to | Time | Guide |
|---|---|---|---|---|
| Analysis | Verbal Analysis | Judge statements about a passage: True, False or Cannot say | 6 min | [Verbal Analysis](docs/sections/verbal-analysis.md) |
| Analysis | Numerical Analysis | Answer questions from tables and charts | 6 min | [Numerical Analysis](docs/sections/numerical-analysis.md) |
| Analysis | Diagrammatic Analysis | Work out what operators do to rows of shapes | 6 min | [Diagrammatic Analysis](docs/sections/diagrammatic-analysis.md) |
| Comprehension | Verbal Comprehension | Judge statements about everyday work passages | 4 min | [Verbal Comprehension](docs/sections/verbal-comprehension.md) |
| Comprehension | Numerical Comprehension | Answer simple questions from work tables | 4 min | [Numerical Comprehension](docs/sections/numerical-comprehension.md) |
| Comprehension | Error Checking | Find the row where a copy differs from the original | 1.5 min | [Error Checking](docs/sections/error-checking.md) |

Every sub-test guide has the same parts: what it measures, how the questions look, a step-by-step method, the traps that cost points, timing, 3 original practice items with explanations, and a score table.

## How to use this repo

- **Read on GitHub.** Every page has links to the previous page, the next page and back to these contents.
- **Only study your test's three sub-tests** unless you are unsure which test you have.
- **Use a timer.** Swift is about pace. Each guide gives a target time for its items.
- **Test yourself honestly.** Answers are hidden under "Answers and explanations". Commit before you open them.
- **Keep a miss log.** The [study plans](docs/study-plans.md#how-to-review-a-missed-item) show how.
- **Practise timed.** For Swift Analysis, the [free practice test on PrepClubs](https://prepclubs.com/free-practice-tests/saville-swift?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=saville-swift) runs the full 18 minutes. For both tests, Saville's own [practice tests](https://www.savilleassessment.com/practice-tests) can be repeated as often as you like.
- **Clone or fork it** if you want your own annotated copy. The structure also works as a GitBook space: see [SUMMARY.md](SUMMARY.md).

## About the practice items

All 24 items (18 in the sub-test guides and 6 in the diagnostic) are original, written for these notes. None are taken from Saville's tests, practice materials or any prep site. Diagrammatic rows and error-checking records are written as text so you can work through them anywhere. They follow the published sub-test descriptions so that the methods transfer.
